# Latent Dirichlet Allocation

## Overview

[Latent Dirichlet allocation](https://en.wikipedia.org/wiki/Latent_Dirichlet_allocation) ([Blei, Ng & Jordan 2003](https://www.jmlr.org/papers/v3/blei03a.html)) is the canonical [topic model](https://en.wikipedia.org/wiki/Topic_model): each document is a mixture of $K$ topics, each topic is a distribution over the vocabulary, and each observed word is generated by first drawing a per-word topic from the document's topic mixture and then drawing a word from that topic's vocabulary distribution. The discrete per-word topic assignment is integrated out by a scoped `marginalize` block, yielding the per-word marginal

$$
p(w_{d,n} \mid \theta_d, \phi) \;=\; \sum_{k=1}^{K} \theta_d[k] \; p(w_{d,n} \mid \phi_k).
$$

The classical observation family is [Categorical](https://en.wikipedia.org/wiki/Categorical_distribution) over the vocabulary. QVR's inline distribution surface admits per-dimension independent families but not `Categorical`, so this example realises a *Gaussian-LDA* relaxation ([Das, Zaheer & Dyer 2015](https://aclanthology.org/P15-1077/)): each word is represented by a learned word embedding, each topic by a learned topic embedding mean and scale, and the per-word emission is a Normal whose mean and scale are selected by the per-word topic latent. The discrete topic assignment is still integrated out, so the marginalize block's mathematical role is unchanged; only the emission family changes from Categorical to Normal.

## QVR Source

```qvr
object Doc : 50
object Topic : 8
object Word : 1000

program lda : Word -> Word
    # Dirichlet concentration on the Topic simplex; one shared
    # concentration parameter for the Gaussian-LDA relaxation.
    theta : Topic <- HalfNormal(1.0)
    phi : Topic <- Normal(0.0, 5.0)
    psi : Topic <- HalfNormal(1.0)
    word_idx : Word <- HalfNormal(1.0)

    marginalize z : Topic <- Dirichlet(theta)
        over Doc
        in {
            let phi_nk = factor n : Word, k : Topic in phi[k]
            let psi_nk = factor n : Word, k : Topic in psi[k]
            observe w : Word via word_idx <- Normal(phi_nk, psi_nk)
        }
    return theta

export lda
```

## Walkthrough

The document-topic concentration `theta : Doc` carries the per-document mixing-weight prior (Dirichlet on the simplex inside the marginalize header). The per-topic emission parameters `phi : Topic` and `psi : Topic` are continuous latents on the `Topic` plate: `phi[k]` is the topic embedding centre and `psi[k]` its scale. The per-word fibration `word_idx : Word` indexes each word into its document; supplied at runtime via the observations dict.

The scoped marginalize block

introduces the per-word topic latent $z$ under a [Dirichlet](https://en.wikipedia.org/wiki/Dirichlet_distribution) prior parameterized by the document-shaped `theta`. The two `factor` expressions build per-(`Word`, `Topic`) parameter tensors by gathering `phi[k]` and `psi[k]` for every word position, so the body's `Normal(phi_nk, psi_nk)` log-likelihood genuinely depends on the marginalized topic. The `over Doc` grouping plate fibrates each per-word observation into its document accumulator, and `via word_idx` names the per-observe fibration from `Word` into `Doc`. The runtime [log-sum-exps](https://en.wikipedia.org/wiki/LogSumExp) over the $K$ topics at every word position, integrating $z$ out by pushforward along the projection $\Phi \times \mathsf{Topic} \to \Phi$.

### Relaxation from canonical LDA

Classical LDA's per-word emission is `w ~ Categorical(phi_k)` over the discrete vocabulary, with `phi_k` itself drawn from a Dirichlet. This example replaces the discrete word draw with a continuous Normal emission in a learned word-embedding space; the topic-vocabulary distributions are replaced by per-topic Gaussian centres `phi[k]` and scales `psi[k]`. The marginalize-over-topics structure is identical to the categorical case (a finite mixture with $K$ components per document), and the same SVI inference machinery applies. To recover discrete-word LDA exactly, one would need an inline categorical-over-vocab emission family; that surface is currently a gap in the QVR inline distribution catalog.

## Try it

The runtime exposes the per-row per-class log-likelihood slot `_grouped_ll_z_0` directly, so synthetic experiments supply that tensor and verify that SVI recovers the topic mixing weights from the implied per-document topic proportions.

```python
import torch
from quivers.dsl import load
from quivers.inference import AutoNormalGuide, ELBO, SVI

torch.manual_seed(0)

prog = load("docs/examples/source/lda.qvr")
model = prog.morphism

n_word, n_topic, n_doc = 1000, 8, 50
ll = torch.randn(n_word, n_topic).clamp(max=0.0)
word_idx = torch.randint(0, n_doc, (n_word,))
obs = {
    "word_idx": word_idx,
    "_grouped_ll_z_0": ll,
}

guide = AutoNormalGuide(model, observed_names=set(obs.keys()))
optim = torch.optim.Adam(
    list(model.parameters()) + list(guide.parameters()), lr=2e-2,
)
svi = SVI(model, guide, optim, ELBO())
for _ in range(500):
    loss = svi.step(torch.zeros(1, 1), obs)
print("LDA loss:", loss)
```

## Categorical Perspective

The discrete per-word topic $z : \mathsf{Topic}$ is integrated out by the [pushforward](https://en.wikipedia.org/wiki/Pushforward_measure) along the projection $\Phi \times \mathsf{Topic} \to \Phi$. The grouped marginalize block scatter-sums per-topic per-row log-likelihoods into the `Doc`-indexed accumulator before the log-sum-exp reduction, so the per-document topic mixture is the [right Kan extension](https://ncatlab.org/nlab/show/Kan+extension) along the per-word document fibration $\mathsf{Word} \to \mathsf{Doc}$ in $\mathbf{Kern}$.
